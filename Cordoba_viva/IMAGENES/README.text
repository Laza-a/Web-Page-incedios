IMPORTANTE:
1. Verificá la licencia de cada fotografía.
2. Anotá el autor y la fuente cuando corresponda.
3. No presentes una foto ilustrativa como si fuera evidencia de un incendio real en Córdoba.
4. Si descargás una imagen, cambiá el enlace de la etiqueta <img> por una ruta local, por ejemplo:
   ../imagenes/fauna-silvestre.jpg

Las fotografías de la página inicial están enlazadas desde internet,
