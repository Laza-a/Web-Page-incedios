## 🎯 PASOS PARA DESCARGAR LAS IMÁGENES

### En Google Imágenes:

1. **Abre Google Imágenes** (images.google.com)

2. **En la búsqueda:**
   - Escribe el nombre del animal o tema
   - Haz clic en "Herramientas"
   - Selecciona "Derechos de uso" → "Marcadas para reutilización" o "Uso comercial y no comercial"

3. **Selecciona una imagen:**
   - Debe coincidir con la descripción
   - Preferiblemente de fuente confiable
   - Resolución mínima 400x400px

4. **Descarga:**
   - Click derecho en la imagen
   - "Guardar imagen como..."
   - **Nombre exacto** (ejemplo: `aguara_guazu.jpg`)

5. **Muévela a la carpeta correcta:**
   - `img/animales/` para animales
   - `img/fondos/` para fondos
   - `img/articulos/` para artículos

### Alternativa en Wikimedia Commons:

1. Accede a commons.wikimedia.org
2. Busca el nombre del animal
3. Selecciona una imagen
4. Descarga la versión de 400-600px
5. Cambia el nombre si es necesario
6. Colócala en la carpeta correspondiente

## 🔄 Si una imagen no carga

### Opción 1: Buscar alternativa
- Busca de nuevo siguiendo la guía
- Asegúrate que sea del animal/tema correcto
- Intenta descargada como PNG en lugar de JPG

### Opción 2: Cambiar la referencia
Si descubres que necesitas un nombre diferente, en `index.html` busca:

```html
<img src="img/animales/aguara_guazu.jpg">
```

Y cambia el nombre del archivo manteniendo la carpeta:

```html
<img src="img/animales/otro_nombre.jpg">
```

### Opción 3: Usar URL directa (temporalmente)
En los archivos `.html` puedes usar URLs directas si es necesario:

```html
<img src="https://ejemplo.com/imagen.jpg">
```

Pero es mejor descargar y guardar localmente para velocidad y independencia.

## 🎓 CONSEJOS FINALES

1. **No uses imágenes genéricas**: Asegúrate que sean realmente del animal especificado
2. **Verifica calidad**: Evita imágenes pixeladas o borrosas
3. **Considera el derecho de autor**: Para proyectos educativos, es preferible usar licencia CC0 o CC-BY
4. **Nombres exactos**: Los nombres de archivo importan - usa guiones bajos, no espacios
5. **Tamaño apropiado**: 400-600px es ideal para web educativa
6. **Formatos**: JPG para fotos, PNG para gráficos
