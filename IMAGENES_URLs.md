## 🔗 Cómo funcionan las URLs

### Estructura de URL de Wikimedia Commons
```
https://upload.wikimedia.org/wikipedia/commons/thumb/
[CÓDIGO_HASH]/[TAMAÑO_px]-[NOMBRE_ARCHIVO].jpg
```

**Ejemplo:**
```
https://upload.wikimedia.org/wikipedia/commons/thumb/4/4a/Chrysocyon_brachyurus_%28Maned_Wolf%29.jpg/800px-Chrysocyon_brachyurus_%28Maned_Wolf%29.jpg
```

- **4/4a** = Código de hash
- **800px** = Tamaño de la imagen
- **Chrysocyon_brachyurus** = Nombre del archivo

### Estructura de URL de Unsplash
```
https://images.unsplash.com/photo-[ID]?w=[ANCHO]&q=[CALIDAD]
```

**Ejemplo:**
```
https://images.unsplash.com/photo-1441974231531-c6227db76b6e?w=800&q=80
```

- **photo-1441974231531-c6227db76b6e** = ID único de la foto
- **w=800** = Ancho de la imagen en píxeles
- **q=80** = Calidad (80% de calidad original)

## ⚙️ Cómo cambiar o reemplazar imágenes

### Para cambiar una imagen de animal

1. Abre el archivo `app.js`
2. Busca el animal que deseas cambiar
3. Reemplaza la URL:

```javascript
{
    id: 1,
    nombre: "Aguará guazú",
    // ... otros datos ...
    imagen: "NUEVA_URL_AQUI",  // ← Cambia esta línea
    // ... más datos ...
}
```

### Para cambiar una imagen de artículo

1. Abre el archivo `index.html`
2. Busca la sección de artículos
3. Reemplaza el `src` de la imagen:

```html
<img src="NUEVA_URL_AQUI" alt="Descripción">
```

### Encontrar nuevas imágenes

**En Wikimedia Commons:**
1. Accede a https://commons.wikimedia.org
2. Busca el animal o tema
3. Selecciona una imagen
4. Copia la URL desde la versión de 800px

**En Unsplash:**
1. Accede a https://unsplash.com
2. Busca el tema
3. Abre la imagen
4. Copia la URL personalizada

## 🔍 Información técnica

### Parámetros de Unsplash

- **w** (width): Ancho en píxeles
  - Valores comunes: 400, 600, 800, 1200
- **q** (quality): Calidad de compresión
  - Valores: 0-100 (80 es recomendado)
- **crop** (opcional): Auto-crop a proporciones

### Tamaños en Wikimedia Commons

Los archivos están disponibles en múltiples tamaños:
- 100px - Muy pequeño (iconos)
- 400px - Pequeño (miniaturas)
- 800px - Mediano (tarjetas)
- 1200px - Grande (detalles)
